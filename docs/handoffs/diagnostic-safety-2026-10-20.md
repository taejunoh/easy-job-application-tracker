# 공개 인계: 로컬 진단 안전 유틸리티

상태: 공개용 로컬 유틸리티와 오프라인 테스트를 준비했습니다. main 병합, 배포, 외부 재현은 하지 않았습니다.

이 패키지는 의존성 없는 유틸리티, 명시적으로 실행하는 Node 오프라인 테스트, 이 인계 문서로만 구성됩니다. 유틸리티는 종결 상태가 확인된 빈 환경 인벤토리 검증, 캡처 대기 중 오류·취소 처리와 자원 정리, 출력 스트림 오류의 sticky 처리, 이미 취소된 입력 작업의 시작 방지를 제공합니다. 출력 오류를 안전하게 처리하는 것은 출력 내용의 비밀정보 제거를 뜻하지 않습니다. 모듈은 import 시 파일·네트워크·자격 증명·외부 서비스에 접근하지 않습니다.

공개 오프라인 테스트는 7/7 통과했습니다. 비공개 prototype의 과거 테스트 60/60 결과는 별도 테스트 묶음의 기록이며, 이 공개 테스트 결과와 혼동하면 안 됩니다. 앱 전체 테스트는 green으로 확인되지 않았습니다. 과거 기준 실행에서 4,096건 초과 reconciliation 테스트가 timeout됐고, 후속 전체 테스트도 120초 제한에 걸려 Jest 요약 없이 끝났습니다. 앱 전체 테스트는 이번 패키지 작업 중 다시 실행하지 않았습니다.

외부 재현은 수행하지 않았고 근본 원인은 확인되지 않았습니다. 운영 앱 변경이나 보안 보고서 작성도 이 작업 범위에 포함되지 않았습니다. 이 공개 유틸리티는 비공개/live helper에 연결되지 않았습니다.

## 안전한 후속 작업

Claude는 공개 유틸리티와 오프라인 테스트만 로컬에서 검토하고, 필요하면 이 범위의 테스트를 다시 실행할 수 있습니다. 앱 테스트 기준 실패는 요청이 별도로 있을 때 독립적으로 진단합니다. 비공개 prototype에서 남은 M1 reconciliation 이벤트 의미와 M2 readiness deadline 검토는 이 패키지에서 해결하거나 수정한 것으로 간주하지 않습니다. 외부 재현을 재개하거나 중단된 안전 경계를 우회하는 용도로 이 인계를 사용하지 마세요.

오프라인 테스트 실행:

```sh
node --test scripts/lib/diagnostic-safety.node-test.mjs
```

이 `.node-test.mjs` 파일은 저장소 Jest 설정의 `**/__tests__/**/*.test.ts` 패턴에 포함되지 않으므로 명령을 명시해 실행합니다. 이 결과만으로 앱 전체 테스트 상태를 판단할 수 없습니다.
